# RPC

> **Category:** Networking Basics

---

**RPC (Remote Procedure Call)** is a high-performance communication paradigm that allows a program to execute a subroutine or function on a remote server as if it were a local function call. Modern RPC frameworks (like **gRPC**) use **Protocol Buffers (Protobuf)** over **HTTP/2** transport.

### Modern gRPC Microservice Topology

```
+-------------------------------------------------------------------------+
|                       gRPC / RPC ARCHITECTURE                           |
+-------------------------------------------------------------------------+

  [ Client Microservice ]                         [ Server Microservice ]
  +--------------------+                         +--------------------+
  | Generated Stub     |                         | gRPC Service Impl  |
  +--------------------+                         +--------------------+
           |                                                ^
           | 1. Serialize OrderRequest (Protobuf Binary)   |
           v                                                |
  +-------------------------------------------------------------------+
  | HTTP/2 Multiplexed Binary Streams (TCP Socket Connection)         |
  +-------------------------------------------------------------------+
           |                                                |
           +---------------- 2. Execute Method ------------>+
```

### gRPC / RPC vs REST API Comparison

| Feature | gRPC (Modern RPC Framework) | REST API |
| :--- | :--- | :--- |
| **Protocol Baseline**| HTTP/2 (Multiplexing, Header Compression) | HTTP/1.1 or HTTP/2 |
| **Data Payload Format**| Binary Protocol Buffers (`.proto`) | Text JSON / XML |
| **Contract Schema** | Strictly typed IDL (`.proto` file) | OpenAPI / Swagger (Optional schema) |
| **Performance** | Extremely High (5-10x faster binary serialization)| Medium (Text JSON parsing overhead) |
| **Streaming Types** | Unary, Client Streaming, Server Streaming, Bi-directional | Request-Response only |
| **Browser Support** | Requires gRPC-Web proxy layer | Native browser support |
| **Primary Use Case** | Inter-service microservice IPC, low-latency mobile | Public APIs, web client integration |

### Protocol Buffer Schema Definition Example

```protobuf
syntax = "proto3";

package payment;

service PaymentService {
  rpc ProcessPayment (PaymentRequest) returns (PaymentResponse);
}

message PaymentRequest {
  string user_id = 1;
  double amount = 2;
  string currency = 3;
}

message PaymentResponse {
  string transaction_id = 1;
  string status = 2;
}
```

### Key takeaway

Use **gRPC / RPC** for high-performance, low-latency microservice internal IPC. Protocol Buffers provide strong schema typing, compact binary serialization, and bi-directional streaming over HTTP/2.

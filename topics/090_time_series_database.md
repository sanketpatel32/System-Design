# Time-Series Database

> **Category:** Databases

---

A **Time-Series Database (TSDB)** is a database optimized for storing, indexing, and querying sequences of data points ordered by timestamp. TSDBs excel at ingesting high-volume append-only write streams generated by IoT sensors, system telemetry metrics, application logs, and financial tickers.

### System architecture

```
                     +-----------------------------------+
                     |      Metrics / Telemetry Stream   |
                     +-----------------------------------+
                                       |
                                       v
                     +-----------------------------------+
                     | TSDB Engine (Timescale / Influx)  |
                     +-----------------------------------+
                                  /         \
           High-Speed Append Writes/           \ Aggregation Queries
                                  v             v
                     +-----------------+   +------------------+
                     |  In-Memory WAL  |   | Downsampled Disk |
                     |  & Chunk Buffer |   |  Hyper-tables    |
                     +-----------------+   +------------------+
```

### Core mechanics & optimizations

1. **Append-Only Write Pattern**: Data points are continuously appended; updates and deletes are rare.
2. **Time-Partitioned Chunks (Hypertables)**: Data is automatically partitioned into time-based tables (e.g., 1-hour or 1-day chunks), keeping recent index chunks small enough to fit in RAM.
3. **Data Compression**: Specialized algorithms (e.g., Gorilla compression for floats, Delta-of-delta for timestamps) compress raw metric streams by up to 90%.
4. **Automated Retention & Downsampling**: Older fine-grained data (e.g., 1-second metrics) is downsampled into rollups (e.g., 1-minute averages) and expired via retention policies.

### TSDB vs Relational DB Matrix

| Feature | Time-Series Database (TSDB) | Standard Relational Database (RDBMS) |
| :--- | :--- | :--- |
| **Write Workload** | High-volume continuous append-only writes | Mixed random inserts, updates, and deletes |
| **Data Retention** | Automated expiration & continuous aggregation | Manual row deletion (`DELETE WHERE`), expensive vacuuming |
| **Compression Ratio**| High (≈ 80-90% using Delta/Gorilla) | Low-Moderate standard page compression |
| **Query Pattern** | Time range aggregations (`AVG`, `MAX` over interval)| Complex JOINs across normalized entities |

### Key takeaway

Time-Series Databases optimize high-throughput timestamped append operations through time-based partitioning, specialized compression, and automated downsampling, making them ideal for monitoring metrics, IoT telemetry, and financial data.

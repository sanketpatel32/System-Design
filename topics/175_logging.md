# Logging

> **Category:** Observability

---

Logging is the practice of **recording discrete, time-stamped textual or structured events generated by application code and infrastructure**. Logs provide detailed diagnostic context explaining *what happened* during system execution, enabling developers to debug errors, audit activity, and trace operational workflows.

### Structured Logging Pipeline Architecture

Applications generate JSON-structured log records, which log shippers collect, queue, index, and visualize inside centralized logging platforms.

### Log Record Schema Example (Structured JSON)

```json
{
  "timestamp": "2026-07-24T12:30:45.123Z",
  "log_level": "ERROR",
  "service_name": "payment-service",
  "trace_id": "4bf92f3577b34da6a3ce929d0e0e4736",
  "span_id": "00f067aa0ba902b7",
  "user_id": "usr_99812",
  "message": "Payment processing failed due to upstream gateway timeout",
  "error_code": "GATEWAY_TIMEOUT",
  "duration_ms": 5002,
  "environment": "production"
}
```

### Logging Levels & Standard Usage Matrix

| Log Level | Purpose & Meaning | Production Recommendation |
| :--- | :--- | :--- |
| **`FATAL` / `EMERGENCY`**| System is unusable; process is crashing immediately | Alert On-Call Engineers immediately |
| **`ERROR`** | Request processing failed due to error; system operational | Index and track in error monitoring (Sentry/Datadog) |
| **`WARN`** | Unexpected event occurred; system degraded but recovered | Monitor trends for degradation spikes |
| **`INFO`** | Normal operational events (e.g. User Login, Order Placed) | Log in production; sanitize sensitive PII data |
| **`DEBUG` / `TRACE`**| Fine-grained diagnostic logs for development | Disable in production (high storage volume) |

### Key Best Practices & Production Rules

- **Use Structured Logging (JSON)**: Always log in key-value JSON format rather than unformatted plain text strings to enable rapid indexing and filtering.
- **Sanitize PII & Credentials**: Mask credit card numbers, passwords, JWT tokens, and PII data before logs hit disk.
- **Log Correlation IDs**: Include a `trace_id` in every log entry to trace requests across microservices.

### Key takeaway

Use **structured JSON logging with embedded trace IDs and sanitized PII**, shipping logs asynchronously to a centralized indexer (Elasticsearch/Loki) for rapid query analysis.

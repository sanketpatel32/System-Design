# TLS (Transport Layer Security)
> **Category:** Security

---

### Overview
**Transport Layer Security (TLS)** is a cryptographic protocol designed to provide end-to-end communication security over a computer network. It operates above the Transport Layer (TCP) and guarantees three core security pillars: **Confidentiality** (encryption), **Integrity** (message authentication codes), and **Authenticity** (digital certificates).

### TLS 1.3 Handshake Architecture

```
Client                                                  Server
  |                                                        |
  | -------- ClientHello (Supported Ciphers, KeyShare) ---> |
  |                                                        |  [Generate ECDH Shared Secret]
  |                                                        |  [Validate Certificate]
  | <------- ServerHello (Selected Cipher, KeyShare) ------ |
  | <------- EncryptedExtensions, Certificate, Finished -- |
  |                                                        |
[Generate ECDH Shared Secret]                              |
[Validate Certificate]                                     |
  |                                                        |
  | -------- Finished (Encrypted Application Data) ------> |
  |                                                        |
  |<====== 1-RTT Symmetric Encrypted Channel Established =====>|
```

### Cipher Suite Breakdown
A standard TLS 1.3 cipher suite specifies the key exchange, bulk encryption, and message authentication algorithm:

$$\underbrace{\text{TLS}}_{\text{Protocol}}\_\underbrace{\text{AES\_128\_GCM}}_{\text{Symmetric Encryption \& AEAD}}\_\underbrace{\text{SHA256}}_{\text{Cryptographic Hash / HKDF}}$$

### Protocol Comparison: TLS 1.2 vs TLS 1.3

| Metric / Feature | TLS 1.2 | TLS 1.3 |
|---|---|---|
| **Handshake Latency** | 2-RTT (2 Round Trips) | 1-RTT (or 0-RTT via Session Resumption) |
| **Static RSA Key Exchange** | Supported (Vulnerable to Forward Secrecy loss) | **Removed** (Only Perfect Forward Secrecy via ECDHE) |
| **Weak Ciphers (RC4, 3DES, CBC)** | Supported | **Removed** (Only AEAD ciphers: AES-GCM, CHACHA20-POLY1305) |
| **Handshake Encryption** | Plaintext SNI & Certificates exposed | Encrypted Certificate & Extensions |

### Performance Optimization Techniques
1. **TLS Session Resumption**: Reuses previously negotiated cryptographic parameters via **Session Tickets** (RFC 5077) or **PSK (Pre-Shared Key)** for 0-RTT resumption.
2. **OCSP Stapling**: Server fetches signed Certificate Revocation Status from Certificate Authority (CA) and staples it to the handshake, eliminating client OCSP lookup latency.
3. **ALPN (Application-Layer Protocol Negotiation)**: Negotiates HTTP/2 or HTTP/3 during the TLS handshake without extra round trips.

### Key takeaway
**TLS 1.3** provides sub-millisecond security by reducing handshake latency to **1-RTT**, mandating **Perfect Forward Secrecy (PFS)**, and enforcing modern AEAD ciphers while deprecating vulnerable legacy algorithms.

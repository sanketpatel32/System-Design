# TLS

> **Category:** Security

---

TLS (Transport Layer Security) = **the cryptographic protocol that secures communication**
over a network (HTTPS, SMTPS, etc.).

### What TLS does
- **Confidentiality**: encrypts traffic, can't be eavesdropped.
- **Integrity**: detects tampering.
- **Authentication**: proves server identity (certificates).
- Optional: client authentication (mTLS).

### The handshake (TLS 1.3)
```
1. ClientHello: supported ciphers, key share, random.
2. ServerHello: chosen cipher, key share, cert.
3. (Key derivation via ECDHE.)
4. Encrypted data flows.
```
- 1 round trip (TLS 1.3) vs 2 (TLS 1.2).
- 0-RTT resumption for repeat connections.

### Certificates
- Server cert proves identity.
- Signed by a CA (Certificate Authority) the client trusts.
- Contains: domain, public key, validity, CA signature.
- Let's Encrypt: free, automated certs.

### Cipher suites
- Key exchange: ECDHE.
- Authentication: RSA / ECDSA.
- Bulk encryption: AES-GCM, ChaCha20.
- MAC: GCM (integrated), Poly1305.
- Modern: TLS 1.3 with AEAD ciphers only.

### mTLS (mutual TLS)
- Both sides present certificates.
- Common in service mesh (Istio, Linkerd).
- Strong auth without passwords.

### TLS termination
- Ends at load balancer / reverse proxy.
- Plain HTTP internally.
- Reduces load on app servers.

### Common issues
- Expired certs (Cloudflare outage 2020).
- Mixed content (HTTP resources on HTTPS page).
- HSTS not set (downgrade attacks).
- Old TLS versions (1.0/1.1 deprecated).

### Key takeaway
TLS secures communication: confidentiality, integrity, authentication. Use **TLS 1.3**, free
certs from Let's Encrypt, mTLS for service-to-service. Automate cert renewal. Set HSTS to
prevent downgrade.
